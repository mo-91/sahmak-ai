# سهمك AI — Web

هذه نسخة ويب مستقلة تعمل على Google Chrome وأي متصفح حديث.

## تشغيل محلياً

ثبّت Node.js 20 أو أحدث، ثم:

```powershell
$env:ALPHA_VANTAGE_KEY="مفتاحك_الخاص"
npm start
```

ثم افتح:

http://localhost:8080

## النشر على الإنترنت

ارفع المشروع إلى خدمة استضافة تدعم Node.js 20+، وضع متغير البيئة:

ALPHA_VANTAGE_KEY

ولا تضع المفتاح داخل ملفات `public`.

يجب أن يكون الموقع عبر HTTPS عند النشر العام.

## وظيفة التحليل

الإصدار الحالي يستخدم:
- SMA 20
- SMA 50
- RSI 14

ويعطي:
- صعود
- هبوط
- غير واضح
- قوة إشارة
- أسباب الإشارة

قوة الإشارة ليست احتمال نجاح مضمون.

## قبل النشر التجاري

1. تنفيذ Backtesting وWalk-forward testing.
2. عرض دقة النموذج على فترة اختبار محددة.
3. إضافة صفحة سياسة خصوصية وشروط استخدام.
4. التحقق من حقوق استخدام بيانات السوق من مزود البيانات.
5. إضافة حماية ومراقبة للـ API ومعدلات الطلب.
6. استخدام HTTPS.
